## 二、电脑版怎么用

**推荐用安装程序**：双击 `RC2搞机工具箱-安装程序.exe`

1. 第一页读完免责声明，点「同意并继续」（会记一次，以后不再问）
2. 选安装位置（默认 `C:\Users\你的用户名\AppData\Local\RC2DeviceToolbox`，不用管理员权限）
3. 点「开始安装」，30 秒左右装完
4. 完成页会问你要不要立即启动

安装程序会自动建**桌面快捷方式**和**开始菜单快捷方式**，安装目录里有
`卸载 RC2 搞机工具箱.bat`，双击就能删干净。

**所有工具都打包在 exe 里了**：adb、fastboot、scrcpy、界面、图标，不用另外装任何东西，
也不需要 Python。拷到别人电脑上双击就能用（Windows 10/11）。

### 连设备
1. 用能传数据的 USB 线把遥控器连电脑（不能只是充电线）
2. 遥控器上如果弹「允许 USB 调试」就点允许
3. 打开工具箱，顶栏应该显示绿色的 `DJI RC 2 · xx℃ · xxx MB`

### 刷 Root 的正确流程（重要）
Magisk 的规矩是「提取 boot → 用 Magisk App 打补丁 → 刷回去」，工具帮你做第 1、4 步：

1. 进「刷机/恢复」→「刷 Root（Magisk）」→ 点 **提取 boot 镜像**
   （这一步同时就是**备份**原厂 boot，出问题能救回来）
2. 把提取出来的 `.img` 传到遥控器
3. 遥控器上打开 **Magisk App → 安装 → 选择并修补一个文件**，选那个 img，
   等它生成 `magisk_patched-xxxxx.img`
4. 把它拷回电脑 → 点 **选择补丁镜像**（会校验大小）→ 点 **刷入补丁**
5. **重启**遥控器，Magisk 里能看到版本号就成了

刷坏了就按住「返回键 + 电源键」进 fastboot，用「恢复备份」刷回去。

### 投屏
DJI 的 ROM 从 SELinux 层拦了 `app_process`，scrcpy 的服务端起不来（这是硬限制，不是 bug）。
所以投屏改成「截图推流」：约 **1-2 帧/秒**，能看、能点、能滑，但不是 60 帧的游戏级投屏。
点击是直接往 `/dev/input/event2` 写触摸事件（`input tap` 会被这台机器静默吞掉）。

## 三、手机版怎么用

`RC2工具箱-v2.25.apk` → 装到遥控器：

```
adb install -r --no-incremental --abi arm64-v8a RC2工具箱-v2.25.apk
```

装完第一次打开会先给你看条款，点同意后永久记住。功能包括：
总览 / 性能 / 风扇温度 / 虚拟内存（zram+磁盘 swap）/ 开机动画 / 文件 /
应用 / 模块 / 日志 / 网络 等 14 个页面。

- **开机动画**：支持「同步原时长」（4 秒视频就播 4 秒）和「手动设置」两种模式；
  帧数 12-120、帧率 10-30 可调；生成过程流式写 zip，不会把内存吃爆。
- **虚拟内存关闭**：现在是纯本地操作（swapoff → 写 disable 标记 → 删文件），
  秒级完成，不会再卡死；再打开也能自动重建。

## 四、Magisk 模块（02 文件夹）

按需刷，进 Magisk App → 模块 → 从本地安装。详细说明见里面的 `README-模块说明.md`。

最常用的三个：
- `02-ADB直接ROOT`：让 adb 一上来就是 uid 0（工具箱很多功能依赖它）
- `03-工具箱免授权弹窗`：配合工具箱用，省掉每次授权确认
- `04-全脚本合集`：26 个运维脚本，含**黑屏急救** `fix_screen.sh`

⚠️ 刷模块前先确认 `/data/adb/modules` 里没有同名旧模块；
刷完第一个先重启看能不能正常开机，再刷下一个。

## 五、几条保命铁律（务必记住）

1. **不要 unexport pwmchip0**——那是屏幕背光，黑屏了用 `sh /data/adb/modules/rc2_allscripts/scripts/fix_screen.sh` 救
2. **不要关 zram**，也不要一次性 dd 超过 1GB 的文件（可用内存只有 1.7GB）
3. **不要尝试回锁 Bootloader**——RC2 有大疆加密校验，回锁直接变砖
4. `swappiness` 不要超过 100，`extra_free_kbytes` 不要超过 32MB
5. 刷分区只刷 `boot_a/boot_b/dji_apk/vbmeta_a`，别碰别的数据分区
